# 第11章　境界の引き直し

出荷モジュールを切り出します。境界は一度で正解を引けるものではない、という前提の章です。

```bash
./gradlew test
```

Docker は必要です。Docker Desktop や OrbStack を起動しておいてください。

## この章の要点

切り出しても `domain` と `infrastructure` は1バイトも変わりません。
