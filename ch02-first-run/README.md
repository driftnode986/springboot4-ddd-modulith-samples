# 第2章　まず動かす

4つのモジュールを立ち上げ、構造を検証するテストを書きます。壁を壊すとテストが赤くなることまで確かめます。

```bash
./gradlew test
```

`./gradlew test` だけなら Docker は不要です。ただし本章の後半でアプリケーションを
起動するときは PostgreSQL が要ります。

```bash
docker compose up -d
./gradlew bootRun
```

## この章の要点

パッケージを分けただけでは何も強制されません。`ModularityTests` が壁の役目をします。
