# 第8章　集約

どこまでを1つのまとまりとして扱うかを決め、不変条件を集約の中に集めます。

```bash
./gradlew test
```

Docker は不要です。

## この章の要点

1回のトランザクションで変更するのは1つの集約まで、という原則をコードに落とします。

## コンパイルが通らないことを確かめる

`probe/` に、集約の外から直接触ろうとするファイルを置いてあります。
Gradle のソースセットには含めず、`javac` に直接渡して失敗を確かめます。
手順は [probe/README.md](probe/) にあります。
